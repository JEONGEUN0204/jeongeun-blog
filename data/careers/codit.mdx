### 1. 회의록 상세 페이지 리뉴얼

#### 문제/배경

- 회의록 상세 페이지에 레거시 코드가 누적되어 잦은 버그 발생
- 기능 추가 시 사이드 이펙트가 빈번하게 발생하여 유지보수 비용 증가

#### 해결 및 효과

- 기존 레거시 코드를 전면 재구성하여 상세 페이지를 신규 개발
- 비정상 동작 케이스를 정리하고 렌더링·상태 관리 로직 개선<br/>
  → 회의록 관련 버그 발생률 대폭 감소(주요 이슈 재발 0건)<br/>
  → 유지보수 및 기능 확장 용이성 확보

### 2. 챗코딧(ChatCODIT) 서비스 분리 및 Next.js 마이그레이션 (진행중)

#### 문제/배경

- 챗코딧이 코딧 플랫폼과 동일한 도메인·코드베이스를 사용하여 확장성과 독립성에 한계 존재
- 서비스 성격에 맞는 구조 분리가 필요

#### 해결 및 효과

- 코딧을 별도 서비스로 분리하며 Next.js 기반 신규 프로젝트 세팅 및 마이그레이션 진행

- 서비스 특성을 고려해 SEO를 우선한 라우팅 구조 설계<br/>
  → 다국어 URL 기반 라우팅 구조 설계 및 적용<br/>
  → 검색 엔진 색인을 고려하여 랜딩 페이지는 리다이렉트 없이 직접 노출되도록 처리
- 불필요한 리다이렉트로 인한 크롤링 손실 방지 및 페이지 접근성 개선<br/>
  → 검색 엔진 친화적인 URL 구조 확보<br/>
  → 서비스 초기 SEO 성능 및 확장성 기반 마련

### 3. ESLint 설정 개선 및 프로젝트 표준화

#### 문제/배경

- 기존 ESLint 설정이 정상적으로 동작하지 않아 코드 품질 관리가 어려움
- 팀 내 코드 스타일 편차 발생

#### 해결 및 효과

- `@rushstack/eslint-config`를 도입하여 프로젝트에 맞게 규칙 재정의

- TypeScript·React 환경에 맞는 린트 설정 정비<br/>
  → 정적 분석 신뢰도 향상<br/>
  → 리뷰 단계에서의 코드 품질 이슈 감소

### 4. 챗코딧 답변 생성 단계별 인디케이터 UX 개선

#### 문제/배경

- AI 답변 생성 과정이 사용자에게 불투명하여 대기 시간이 길게 느껴짐

#### 해결 및 효과

- 답변 생성 단계를 세분화하여 단계별 인디케이터 문구를 조건 분기 처리

- 진행 상황을 명확히 인지할 수 있도록 UX 개선<br/>
  → 체감 대기 시간 감소 및 사용자 신뢰도 향상<br/>
  → 답변 생성 과정 이탈률 감소

### 5. 커스텀 메뉴 폴더 및 이슈 자동 생성 기능 개발

#### 문제/배경

- 연령대가 높은 사용자에게 폴더/이슈 수동 생성 과정이 복잡하게 인식됨

- 초기 사용 진입 장벽 존재

#### 해결 및 효과

- 문장을 입력하면 적절한 메뉴 폴더와 이슈를 자동 생성하는 기능 개발

- 사용자 입력 의도를 기반으로 구조를 자동 설계<br/>
  → 콘텐츠 생성 소요 시간 단축(수작업 대비 대폭 감소)<br/>
  → 고연령 사용자 사용성 및 접근성 개선

### 6. 서비스 전반 버그 픽스 및 안정성 개선

#### 문제/배경

- 신규 기능 개발과 병행되며 자잘한 UI/로직 버그 다수 발생

  → 서비스 안정성 향상
